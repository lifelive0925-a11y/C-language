# C Language Practice Repository
This Repository stores C language learning and experimental codes(strcpy, strlen, memcpy)

## File List
- strcpy.c: Handwritten implementation of strcpy;
- memcpy.c: Handwritten implementation of memcpy;
- strlen.c: Handwritten implementation of strlen;
- square_root.c: Approximating the square root of a positive number;
- reverse.c: Change the binary number from left to right;
